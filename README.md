# 红警2修改器 v0.3.0

面向红色警戒2原版 **1.006 / game.exe**。EXE发行版适用于64位 Windows 10/11，无需安装 Python；源码运行需要 Python 3.10 或更新版本 + PySide6。不支持尤里的复仇 `gamemd.exe`。

说明核对日期：2026-09-29。功能已接入不等于已完成全部实机验证，具体限制见下文及进度记录。

## 启动

### EXE发行版（推荐）

从 [GitHub Releases](https://github.com/lyfhc0305/ra2-trainer/releases) 下载 `RA2Trainer-v0.3.0-windows-x64.exe`，双击即可运行；也可下载包含 EXE 和本说明的 ZIP，解压后运行 `RA2Trainer.exe`。发行文件不包含游戏本体和个人设置。

- 把 EXE 放到自己可写入的文件夹。设置保存在 EXE 同目录的 `.state.json`，只有点击“保存当前功能状态”才保存功能状态；移动程序时可一起移动该文件。
- 可先手动启动红警2并进入单机战局，修改器会自动附加。若想使用修改器里的启动游戏按钮，将 `游戏本体` 文件夹放在 EXE 同目录或上一级目录，也可把 EXE 直接放进有 `ra2.exe` 的游戏目录。
- 更新时先关闭旧修改器，再替换 EXE，保留自己的 `.state.json`；首次单文件启动需要解压内置运行库，可能稍等几秒。
- EXE尚未做代码签名。发布页同时提供 `SHA256SUMS.txt`，可用 `Get-FileHash -Algorithm SHA256 文件路径` 核对下载文件。

### 源码运行

在上一级文件夹双击 **启动红警2修改器.cmd** 即可启动；它会自动查找 Python、检查依赖并保持错误提示可见，不需要先打开命令行。重复双击只会提示已有窗口，不会同时附加两个修改器。首次使用若提示缺少依赖，按提示在`ra2-trainer`目录安装`requirements.txt`；启动脚本不会自行下载。

也可在命令行运行，或用`启动红警2修改器.cmd --check`只检查环境而不打开窗口和游戏：

```powershell
cd ra2-trainer
pip install -r requirements.txt
python main.py
```

通过“游戏本体/ra2.exe”启动游戏并进入单机战局。修改器自动附加。
更新代码后需要关闭旧修改器再重新打开，否则旧进程会继续使用旧逻辑。

## 当前开发状态

目前69个界面条目分为10个分区，其中51个游戏功能已接入、15个待开发，另有3个调试工具；**尚未完成全部功能**。
详细历史、地址依据与测试见 [PROGRESS.md](PROGRESS.md)。新增超武功能暂缓。

已接入的游戏功能：

- 资金、金钱不减、无视建造距离、全图、雷达。
- 快速建造：仅己方约10倍速度；瞬间建造：立即进入最后付款步骤。
  两者同时开启时瞬间建造优先。资金不足仍等待，手动暂停仍有效，建筑仍需放置。
- 扩展建造队列：仅己方上限扩展至999，仍保留单位自身数量限制。
- 科技全开：己方开放正常跨阵营科技及建造前提，仍需实际类别工厂；美国显示其空军指挥部，其他阵营显示通用版本，避免两个相同机场。解除建造限制独立放宽前提与数量上限；两个开关均不放出原版硬禁用类型。
- 反隐身伪装：仅己方识破隐形与伪装单位。全目标攻击让己方已有武器瞄准并命中空中目标，仍受射程、弹道和装填限制。
- 心灵探测：全图显示非盟军载具、步兵、飞机的移动与攻击路线，效果等同心灵探测器覆盖全图；盟军和建筑保持原样，关闭后恢复。
- 战役：冻结任务倒计时（保持剩余时间，任务中途重设计时器会按新时间继续冻结）；任务直接胜利（与地图胜利触发相同，战役进入下一关）；盟军/苏军战役起始关（在主菜单设置1～12后点对应战役按钮，关闭修改器后恢复从第1关开始）。
- 经济（仅己方）：采矿收入倍率0.1～100（含净化工厂加成）；矿石无限（己方矿车不消耗矿区）；修理免费（建筑修理与维修厂）；出售全额退款。
- 战斗（仅己方）：射速倍率1～10（开火间隔缩短为1/倍率）；射程倍率0.5～5（射程判定与索敌距离同时放大）。
- 反尤里控制（仅己方）：己方单位和建筑在游戏的“心灵控制免疫”判定中视为免疫，尤里不会以它们为目标也无法控制；开启前已被控制的单位不会自动放回。
- 功能方案：左侧“功能方案”可一键应用内置方案（全部关闭、战役轻松档、遭遇战纯享档）或自定义方案，也可把当前开关和倍率另存为方案；未进入游戏时应用，会在附加游戏后生效。
- 无敌模式：拦截己方步兵、载具、飞机和建筑的普通正向伤害；其他势力不变。
  不阻止出售、脚本强制销毁、工程师占领或心灵控制；关闭后恢复正常受伤。
- 无限电力：仅补足己方供电，在游戏重算电力时同步建筑和雷达；关闭后恢复实际供电。
  仍需要拥有正常工作的雷达建筑。本功能不替代独立的“雷达+间谍卫星”。
- 己方单位血量、装甲、火力、持续三星。
- 复制选中的己方载具/步兵：一次批量放在游戏内鼠标附近，每次最多500个；按数量向周围寻找可放置位置，最大搜索半径15格。步兵可多人同格，载具不重叠，能否放下由游戏规则判断；放置失败会销毁未放置对象。
  放置位置须与鼠标所在格处于同一可达区域；鼠标格不可进入时，以最近的首个成功放置格为准，减少单位生成后被困在孤立地形的情况。
  不复制经验、载员、伤害等实例状态；飞机和建筑尚不支持。
- 占有/转移选中单位或建筑：调用游戏的归属变更接口。
- 时空兵快速落地：仅己方时空移动步兵后续传送的落地计时缩至1游戏帧；保留原版落点检查和武器抹除攻击计时。开启前已经在等待的那次传送不追溯修改；完整画面动画是否同步结束未单独验证。
- 陆地单位水面行走：己方原本不能下水的普通步兵、履带与轮式地面战车可经过海滩进入水面，正常寻路、移动，并接近射程外目标寻找射击位置；开启时己方兵营、战车工厂和复制中心也可设置跨水面集结点，目标格被占时后续单位仍可在附近水面集结；谭雅等原生两栖单位、敌军、舰船和飞机不变。关闭后，仍在水面或海滩的受影响单位可以返岸，抵达原生可通行陆地后不再获得水面能力。
- 选中步兵进驻建筑：按“执行”或其自定义快捷键一次，对按下时选中的己方驻防步兵批量下达进驻命令；在各步兵30格内寻找有空位的己方或平民建筑，并通过游戏原生驻防资格检查。再次执行会保留在途名额，不向已经在途进驻的步兵重复下令；无可用目标时日志会提示原因。
- 超武无等待：立即充能己方已获得且未暂停的超武/空降支援。
- 自动修理建筑、选中己方单位持续回血。
  建筑维修量可设置为0（每次更新恢复满血）或1～1000000（每15个游戏帧恢复指定血量，实际间隔随游戏速度变化）。
  满血及手动提升到默认上限以上的血量不会被降低，死亡对象不会复活。
- 坦克自动维修：仅己方可维修的履带/轮式地面战车（含矿车、装甲运输车）按游戏维修厂规则逐步修复；原版通常每15游戏帧加8血。正在使用维修厂的车辆交由原版修理，避免双倍速度。舰船、飞机、步兵、建筑不适用；暂停和关闭期间不累积维修量。
- 空军指挥部机位倍率：设置己方同一机场的逻辑机位为原版4位的1～16倍；额外机位共用原4个停机坪坐标。恢复1倍时保留已联系的高槽飞机并阻止新的超额申请。实机已验证2倍下总机位和联系槽均从4扩至8、原4架飞机仍在；第5架实际生产、停靠、补弹和再起飞尚未验证。
- 类型编辑：移速倍率、转向速度、视野、成本、是否可选、隐形、探测、辐射免疫。
  **所有势力同类型单位共享这些属性**；有些效果在移动/状态更新后生效。
  提供“还原类型修改”，正常关闭修改器也会还原。

另外提供版本校验、数值扫描、指针查找3项调试功能。

侧栏“快捷键设置”可为所有已接入的修改项目设置组合键，游戏在前台时直接生效。开关类按键切换状态，数值类应用当前输入框的值，动作类执行一次；默认 `Ctrl+Alt+C` 复制选中单位。快捷键在快捷键设置里确认后立即保存。

首次打开时所有功能默认关闭。开关状态、输入值、维修量和机场倍率只在点击侧栏“保存当前功能状态”时写入 `.state.json`，下次打开恢复；没点保存的改动关闭后不保留。旧版本自动写下的设置文件不会恢复功能状态，只保留快捷键。

复制按钮使用游戏最近记录的鼠标位置，所以先将鼠标移到地图空地；鼠标在侧栏或地图外时不会复制。

周期单位刷新在后台执行，滚动和筛选保持响应；后台操作进行中若点击另一修改项目，日志会提示稍后重试。关闭修改器会等待正在执行的操作完成，再恢复补丁和释放游戏连接。

## 运行保护

- 版本/已知补丁字节不匹配时停止写入。
- 多地址补丁失败会尝试回滚，关闭时仅还原本修改器拥有的代码补丁。
- 水面行走与机场机位的控制块驻留在游戏进程里。当前水面行走为 WATER7，支持校验后将 WATER1～6 原址升级，正常升级不必重启游戏；更新代码后仍需重启修改器。遇到无法兼容或校验失败的旧块时，相关功能本局不可用并在日志提示，需重启游戏。
- 对象缓存属于当前连接，写入前重新核对对象身份与归属。
- 对象生成与控制权转移在游戏主线程执行；超时保留仍可能被使用的调用代码及参数。
- 主线程操作期间不要暂停游戏；暂停时请求可能超时，继续游戏后才能完成。
- 关闭持续三星/回血只停止后续刷新，已获得的等级/血量不会回退。

## 验证

```powershell
pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python -m compileall -q trainer tools
```

自动测试不修改游戏，分三层：
- 纯逻辑与故障注入：只需 Python 与 requirements.txt，任何系统都能运行。
- CPU 仿真（`*_emulated.py` 等）：需要 unicorn（已列入 requirements-dev.txt）。缺少时跳过；设 `RA2_REQUIRE_EMULATION=1` 则改为失败，CI 即如此。
- 与本机 game.exe 字节比对：默认读取上一级 `游戏本体/game.exe`，可用 `RA2_GAME_EXE` 指定其他路径。缺少时跳过（原因写在跳过信息里）；设 `RA2_REQUIRE_GAME=1` 则改为失败。游戏文件不进仓库，CI 只跑前两层。

涉及真实战局的测试记录见进度文档；类型属性的战斗效果并未逐一覆盖。

主动运行实机回归前请关闭修改器，保持遭遇战运行：
`python -m tools.production_live_test`、`python -m tools.protection_live_test`、
`python -m tools.ui_live_test`。防护测试会对己方一个健康载具和建筑施加微量伤害后还原血量；
界面集成测试会暂时开启新功能和无限电力并验证维修量，退出时恢复补丁。

## 主要目录

`trainer/app.py` 界面；`mem.py` 进程访问；`executor.py` 主线程队列；
`operations.py` 单位操作；`jobs.py` 后台任务；`hotkeys.py` 快捷键；`power.py` 电力状态同步；`patches.py` 补丁恢复；
`production.py` 己方生产速度/队列；`protection.py` 己方伤害拦截；`tank_repair.py` 地面战车按帧自动维修；
`techno_ai.py` 持续三星与建筑自动修理；`chrono_landing.py` 时空兵传送落地等待；
`water_walk.py` 水面行走与跨水面集结；`auto_enter.py` 选中步兵进驻；`airport_slots.py` 机场机位；
`campaign.py` 战役；`economy.py` 经济；`weapons.py` 射速与射程；`psychic.py` 心灵探测；`psionic.py` 反尤里控制；
`typeedit.py` 类型属性编辑；`units.py` 对象枚举；`tests/` 回归测试。

## 构建Windows发行版

在64位 Windows 和64位 Python 环境中，从项目目录执行：

```powershell
python -m pip install -r requirements-build.txt
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build_release.ps1
```

`dist/RA2Trainer.exe` 为单文件程序；`release/` 输出带版本号的 EXE、ZIP 和 SHA-256 校验清单。构建不会打包游戏、个人设置或测试数据；这些输出目录不提交到 Git，发行文件上传到 GitHub Releases。

可执行 `RA2Trainer.exe --self-test 报告.json` 检查打包后的界面、69项功能清单与反汇编库是否能够加载。该模式不读取个人设置、不附加游戏，检查后自动关闭并写入 JSON 报告；它不替代游戏内功能验证。

打包路径及外部游戏启动的适配依据：[PyInstaller运行时说明](https://pyinstaller.org/en/stable/runtime-information.html)、[外部程序启动注意事项](https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html#launching-external-programs-from-the-frozen-application)。
